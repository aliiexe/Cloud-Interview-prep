Ten lines to remember

1. Region = geography; zone/AZ = isolated failure domain.
2. HA is not the same thing as backup.
3. Scale out = more instances; elasticity = automatic adjustment.
4. S3/Blob = object, EBS/Managed Disk = block, EFS/Files = file.
5. Route 53 / Azure DNS = DNS.
6. VPC / VNet = private cloud network.
7. Lambda / Functions = serverless functions.
8. EKS / AKS = managed Kubernetes.
9. Terraform: init → plan → apply; protect state.
10. Never hard-code secrets; use least privilege.
